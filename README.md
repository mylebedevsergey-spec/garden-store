# Сад и Огород

Учебный интернет-магазин садовых принадлежностей на чистом HTML, CSS и JavaScript, без фреймворков
и сборки. Модули ES, состояние в localStorage, клиентский роутинг, Canvas и Web Worker.

Демо: https://mylebedevsergey-spec.github.io/garden-store/
Код: этот репозиторий.

Локально запускается так:

```
node server.mjs 8099
```

Открыть http://127.0.0.1:8099. Подойдёт и любой статический сервер, если он отдаёт index.html
на неизвестные пути.

## Что внутри

В каталоге двенадцать товаров, четыре категории, поиск с задержкой ввода. Карточка товара открывается
на отдельной странице, там описание, характеристики и две цены, если есть скидка.

Корзина сделана двумя способами сразу: выдвижная панель справа и отдельная страница. Количество
меняется, позиция удаляется, всё сохраняется в localStorage и не теряется после перезагрузки.
Скидки считаются в отдельном потоке, пороги пять и десять тысяч.

Навигация через History API. Есть кнопки назад и вперёд в шапке, работают и штатные кнопки браузера,
позиция скролла восстанавливается при возврате. Прямые ссылки на товар тоже открываются, для этого
в корне лежит 404.html, который запоминает путь и возвращает на index.

На главной есть холст: клик по нему сажает растение, оно вырастает и покачивается. Рисую
в requestAnimationFrame с учётом плотности пикселей, на фоне отдельный холст с частицами.

На странице о магазине есть поле ввода и кнопка, воркер считает количество простых чисел до N.
Миллион даёт 78 498 примерно за восемь миллисекунд, интерфейс при этом не подвисает.

Из доступности: aria-атрибуты, видимые рамки фокуса, закрытие корзины по Esc, поддержка
prefers-reduced-motion.

## Структура

```
index.html          каркас
404.html            возврат на index при прямом заходе
css/index.css       переменные, типографика, общие блоки
css/components/     стили по компонентам
js/app.js           точка входа и обработчики
js/router.js        роутер на History API
js/store.js         состояние и localStorage
js/data.js          товары
js/canvas.js        анимации на холсте
js/worker.js        скидки и простые числа
js/components/      карточка, корзина, иконки
js/pages/           каталог, товар, корзина, о магазине
server.mjs          дев-сервер
deploy.sh           сборка docs/ для Pages
```

## Публикация

```
./deploy.sh garden-store
git add docs && git commit -m "deploy" && git push
```

В настройках репозитория Pages указывается ветка main и папка /docs. Скрипт подставляет
в index.html базовый путь /garden-store/, поэтому ссылки и модули работают из подкаталога.

## Технологии

HTML, CSS (Grid, Flexbox, переменные, 3D-трансформации, keyframes, backdrop-filter),
JavaScript (модули, делегирование событий), браузерные API: History, Canvas 2D, Web Worker,
localStorage.
