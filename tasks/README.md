# Учебные страницы к заданиям по HTML/CSS

Здесь лежат отдельные страницы под промежуточные задания курса. Каждая в своей папке и со своей ссылкой.

- `3d/` — 3D-трансформации: переворот карточки, вращающийся куб, параллакс по слоям.
- `grid/` — раскладка страницы на CSS Grid: области через `grid-template-areas` и каталог на `auto-fit`.
- `skeleton/` — семантический каркас страницы без CSS, с комментариями по тегам.

Адреса на GitHub Pages:

- https://mylebedevsergey-spec.github.io/garden-store/tasks/3d/
- https://mylebedevsergey-spec.github.io/garden-store/tasks/grid/
- https://mylebedevsergey-spec.github.io/garden-store/tasks/skeleton/
